# Personal Portfolio Website

## About

This is my personal portfolio website created using HTML, CSS, and JavaScript. It showcases my skills, education, projects, and contact information in a clean and responsive design. The website is fully responsive and works well on desktop, tablet, and mobile devices.

---

## Features

- Responsive Navigation Bar
- Home Section
- About Me Section
- Skills Section
- Education Section
- Projects Section
- Resume Download Button
- Contact Form
- Social Media Links
- Dark Mode
- Smooth Scrolling
- Mobile Responsive Design

---

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download or clone this project.
2. Open the project folder in VS Code.
3. Open `index.html`.
4. Run the project using Live Server or any web browser.
