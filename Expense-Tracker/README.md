# Expense Tracker

## Project Description
Expense Tracker is a simple web application to manage daily income and expenses.

## Features
- Add Transaction
- View Current Balance
- View Total Income
- View Total Expense
- Delete Transaction
- Filter by Category

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download the project.
2. Open the project folder.
3. Open `index.html` in your browser.
